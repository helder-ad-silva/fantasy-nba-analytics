Fantasy NBA
Analytics Dashboard

A private, non-commercial analytics tool for a single Yahoo Fantasy Basketball league. Built to transform weekly matchup and player statistics into clear, actionable insights.

What the project will do

Weekly matchups

Compare scoring categories and identify opportunities across head-to-head matchups.

Player insights

Review player statistics, roster composition and game schedules.

Historical trends

Visualise team performance over time in Microsoft Excel dashboards.

Technology and API usage

The planned application will use Python for local data processing, Microsoft Excel for reporting, and the official Yahoo Fantasy Sports API for authorised, read-only data retrieval using OAuth 2.0.

Scope: one user, one Yahoo Fantasy Basketball league (League ID: 101812). No public accounts, commercial subscriptions, data resale or API write operations are planned.

Project status

This website is an informational landing page. The dashboard and Yahoo API integration are under development and are not currently available as a public service.

Independent personal project. Not affiliated with or endorsed by Yahoo or the NBA.
